# 1日の降雪量がどかっと増える日（大雪日）の特徴調査

気象庁の日別データ（青森、2021年8月〜2026年8月）から、冬（11〜3月）の降雪日を「大雪日」と「ふつうの雪の日」に分けて、同じ日の気象要素を比べた。

- 大雪日 = 日降雪量20cm以上（32日）、ふつうの雪の日 = 1cm以上20cm未満（313日）
- 弘前でも同様に確認（17cm以上＝降雪日の上位約1割を大雪日として34日 vs 297日）

## ファイル
- analyze.py: 2群の比較（中央値、AUC、マン・ホイットニーのU検定）と、気温帯別・気圧変化別の大雪日率
- plot.py: 図の作成
- features.csv: 冬の降雪日ごとの指標と群（青森）
- images/fig1-feature-auc.png: 指標ごとの差の大きさ（AUC）
- images/fig2-distributions.png: 気温・湿度・日照・風速の分布

## 実行
```
cd 02-heavy-snow
../.venv/bin/python analyze.py
../.venv/bin/python plot.py
```

## 結果の要約（青森）
- 差がはっきりある: 気温が低い（日平均 −1.9℃ 対 −0.2℃、日最高 0.1℃ 対 2.3℃）、湿度が高い（91% 対 84%）、日照が少ない（0.1h 対 1.1h）
- 差がない: 風速（平均・最大）、海面気圧の水準、前日からの気圧変化（日平均値で見た場合）
- 前日も降雪ありの割合はやや高い（94% 対 70%）
- 降水量は大雪日で多い（19mm 対 4.5mm）が、雪の量とほぼ同じ現象なので原因ではなく結果
- 気温<0℃ かつ 湿度88%以上の日は大雪日率31%（83日中26日）。それ以外の降雪日は2%（262日中6日）
- 弘前でも気温・湿度は同じ向きの差（日平均 −2.8℃ 対 −0.7℃、湿度 93% 対 87%）。風速は差なし

## 限界
- 大雪日は32日（弘前34日）しかなく、5シーズンの結果。個別の条件の差は目安
- 日別の値なので、低気圧の通過や寒気の流入など、時間単位の動きは見ていない
- 相関・比較であって、因果の証明ではない
