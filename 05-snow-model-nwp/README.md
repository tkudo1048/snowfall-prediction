# 数値予報モデルの値（上空の寒気など）を足すと、翌日の弘前の降雪量・大雪日はどれだけ当たるようになるか

**現在の対象地点は弘前（アメダス 0166）。** 青森を対象にした前回の結果は `README_aomori.md`（結果・図・ログは `results/aomori/`、`images/aomori/`、`logs/aomori/`）。
スクリプトは `--target hirosaki|aomori` で対象地点を切り替えられる（既定は弘前）。結果・図・ログ・最良パラメータは地点ごとのフォルダに分けている。

青森・弘前の日別観測（気象庁）に、気象庁の数値予報モデル（GSM・MSM）の値を特徴量として足し、翌日の弘前の日降雪量(cm)と大雪日（翌日20cm以上）を予測した。
手順・評価の約束は青森のときと同じ（時系列で分割、評価は最後の2冬だけを最後に1回、チューニングは学習データ内の冬単位の前向きCV、各100試行 × seed 7/42/2024）。

- S0（基準）: 観測だけ（青森・弘前の t日以前の日別値）。青森のときの51項目に、弘前の「持続」の4項目を足した55項目。
- SA（運用可能）: S0 ＋ 今日（t日）の数値予報の値（弘前付近と上流2点）。今日の21時までの値だけ、GSM は補間されていない03・09・15・21時の値だけを使う。
  `test_no_leak.py --target hirosaki` で、t日21時より後の数値予報の生データ・補間値と、t日より後の観測を使っていないことを確かめた。
- SB（上限の目安・運用不可）: SA ＋ 明日（t+1日）の数値予報の値。「明日の予報が実況並みに当たった場合」の上限。実際の運用ではこの精度は出ない。

実行日: 2026-10-23（チューニング・評価）。弘前のモデルの評価は1回だけ。ただし探索の段階（`03-snow-correlation`、2021-11〜2026-03）で評価期間を含む弘前の日降雪量を見ており、弘前の設計（持続の4項目を足すなど）は同じ2冬での青森の評価結果を見たあとで決めている。
途中で利用上限により作業が一度中断したが、チューニング（63件）は中断前に完了しており、再開後に再実行はしていない（63件すべて100試行・完了を確認）。

## 結論（評価データ = 2024年・2025年の冬、302日、大雪日20日）

### 運用できる形（SA: 今日までの数値予報を足す）

- 降雪量の平均誤差（MAE）は、S0 から 0.16〜0.21cm（5〜6%）小さくなった（3.31〜3.37cm → 3.10〜3.21cm）。
  - 3手法とも、95%区間（日単位・7日ブロックとも）が0をまたがない（Ridge −0.160、勾配ブースティング −0.203、ランダムフォレスト −0.213cm）。3つの seed すべてで同じ向き。
  - 多重比較の補正はしていない。区間の上端は Ridge −0.027cm、勾配ブースティング −0.087cm、ランダムフォレスト −0.108cm（7日ブロック）。
  - 持続予測（翌日も今日と同じ）よりは0.80〜0.90cm小さい。ただし弘前では持続予測が「常に0」とほぼ同じ（評価MAE 4.007 対 3.987）なので、持続予測は弱い基準。
- 大雪日（翌日20cm以上）は、量の予測ではほぼ当たらない。
  - 予測値20cm以上を「大雪」とすると、S0・SA ともに20日中0日（全手法）。SA の予測の最大は8.8〜12.9cm、実際の大雪日での予測の平均は5.4〜5.7cm。
- 大雪日専用の分類モデル（主に読むのはロジスティック回帰）では、SA が S0 より並べ方が良くなった。
  - ロジスティック回帰の AP: S0 0.195 → SA 0.323（差 +0.128、95%区間 +0.039〜+0.250、7日ブロック）。AUC は 0.828 → 0.872（差 +0.044、+0.014〜+0.079）。
  - ただし判定の線（CVで決定）で「大雪」と出すと、SA は88日出して17日的中（適合率0.19）。20日中17日を拾えるが、空振りが71日ある。
  - 勾配ブースティング分類は AP 0.274 → 0.283 で、差ははっきりしない（区間 −0.135〜+0.161）。
- SA のモデルが数値予報から主に使っていたのは「今日21時の500hPa高度（上空の気圧の谷）」「上流の上空（850hPa気温・700hPa湿度）」だった。

### 運用できない上限（SB: 明日の数値予報が実況並みに当たったとしたら）

- MAE は 2.10〜2.40cm。SA から 0.81〜1.01cm 小さく、95%区間は0をまたがない。
- MSMの降雪量に倍率1.80を掛けただけの予測で MAE 2.27cm。SB の勾配ブースティング（2.14cm）・ランダムフォレスト（2.10cm）とほぼ同じ。
- 大雪日の分類の AP: SB ロジスティック回帰 0.594、勾配ブースティング分類 0.441。MSMの降雪量そのままを点数にすると 0.682（AUC 0.938）。

### ひとことで（青森と並べて）

- 弘前でも、今日までの数値予報を足して減らせた誤差は5〜6%（青森は2〜5%）。弘前では3手法とも区間が0をまたがず、青森より改善がはっきりしていた。
  - ただし「常に0」に対する改善の割合では、S0・SA とも青森のほうが少し良い。地点の違いか評価期間の違いかは、評価2冬では切り分けられない。
- 大雪日を「量」で当てられないのは青森と同じ。大雪日専用の分類では、弘前のロジスティック回帰は SA で AP が上がり、区間も0をまたがなかった（青森は0をまたいだ）。
- 弘前の大雪日は学習データに21日しかなく、CVの AP は0.04〜0.09と低い。評価の2冬（とくに2024年の冬、大雪日12日）は学習期間より雪が多かった。結果はこの条件付き。

## 設計

- 目的変数: 翌日(t+1)の弘前の日降雪量(cm)。予測対象日が11〜3月の日だけ。
- 学習データ: 2015年の冬（2016-01-02〜03-31）〜2023年の冬。1,295日、大雪日21日。
- 評価データ: 2024年の冬（151日、大雪日12日）と2025年の冬（151日、大雪日8日）。
- チューニング・手法・探索範囲・判定の線の決め方は青森と同じ（`README_aomori.md` の「設計」）。分類は20cm（主）と15cm（参考）の2つ。チューニングは63件（回帰3手法・分類2手法×2つの閾値、各3セット×3 seed）。

### 特徴量

- S0（55項目）= 青森のときの観測51項目 ＋ 弘前の「持続」4項目。
  - もとの51項目にも、弘前の今日の降雪量・最深積雪・気温（平均・最高・最低）・降水量・風・日照・前日からの気温の変化はある。
  - 足した4項目: 弘前の積雪の前日差（t−1 → t）、弘前の前日（t−1）の降雪量、弘前の3日間（t−2〜t）の降雪量の合計、弘前の前日の平均気温。青森の同じ種類の項目は材料として残した。
  - 天気概況は青森にしかないので、青森の値を使う（t日の昼と、t−1日の夜。t日の夜は t+1日の0〜6時を含むので使わない）。
- 気温の折れ線（max(0, 2℃ − 日平均気温)）: 青森・弘前の両方の気温で作ったもの（a_cold, h_cold）がもとの51項目に入っているので、そのまま両方使う。
  寒さ×湿度（a_cold_x_humid）は、弘前の湿度が2021年3月以前にないため、青森の気温・湿度のままにした。
- SA（102項目）= S0 ＋ t日の数値予報47項目。弘前付近の GSM・MSM と上流2点（項目の作り方は青森と同じで、地点だけを弘前に替えた）。
  - 850hPa −6℃ の折れ線（max(0, −6℃ − 850hPa気温)）は、弘前付近の GSM 格子点（40.5N 140.5E）の気温で作った。目的変数の地点の上空の寒気を表すため。
- SB（134項目）= SA ＋ t+1日の数値予報32項目（弘前付近と上流2点）。

### 何が効いていたか（解釈）

グループ単位の permutation importance（評価データ、50回の平均。回帰 = MAEの増加cm、分類 = APの低下）
- SA 勾配ブースティング回帰: t日の500hPa高度 0.416、上流点 0.197、観測の気温 0.144、t日の地上の気温・気圧 0.106、t日の上空の気温 0.067、観測の降雪・積雪 0.067、暦 0.062、t日の上空の湿度 0.060。
- SA ランダムフォレスト回帰: t日の500hPa高度 0.463、上流点 0.192、観測の気温 0.169、t日の上空の気温 0.119。
- SA Ridge回帰: 上流点 1.124、t日の500hPa高度 0.978、t日の地上の気温・気圧 0.482、観測の降雪・積雪 0.373。
  Ridge は正則化が弱く（alpha 0.18）、似た特徴量どうしで大きな係数が打ち消し合っている（21時の500hPa高度 −1.072 と 0〜21時の平均 +0.486 など）。並べ替えると打ち消しが崩れて大きく悪くなるので、Ridge の値は大きく出やすい。
- SA ロジスティック回帰（大雪の分類）: 上流点 0.072、t日の地上の降水・降雪 0.040、t日の上空の湿度 0.038、t日の上空の気温 0.031。列単位では上流・西の700hPa湿度 0.042、弘前上空の21時の700hPa湿度 0.037、上流・北西の700hPa湿度 0.034、今日の弘前の降雪量 0.027。
  → 「上空3,000m付近まで湿っていて（雪雲が厚い）、上流の日本海側も湿っていると、翌日の大雪の可能性が上がる」という向き。
- SB 勾配ブースティング回帰: t+1日の地上の降水・降雪 1.487、t+1日の上流点 0.427。列単位では t+1日のMSM降雪量 0.779 が最大。
- 列単位（SA 勾配ブースティング回帰、30回）: t日21時の500hPa高度 0.274、上流・北西の21時の850hPa気温 0.088、500hPa高度のt日中の変化 0.074、21時の海面気圧 0.069、21時の700hPa湿度 0.062、弘前の今日の降雪量 0.047。

## 限界・注意（記事で必ず添える）

- SB は運用できない。t+1日の数値予報の値は「ほぼ実況」の値で、前日に出た予報ではない。MSM の降雪量そのままの参考値も同じ。
- SA も少し楽観的な可能性がある。21時の GSM の値（解析値に近い）には21時以降（〜24時ごろ）の観測が取り込まれている可能性があり、運用で手に入るのは深夜になる。
- 弘前の大雪日（20cm以上）は学習データに21日しかなく、CVの検証冬では12日、2023年の冬は0日。CV の AP は 0.04〜0.09 と低く、チューニングが大雪日の少なさに強く左右されている。
- 評価の2冬は学習期間より雪が多かった（20cm以上の日: 評価 6.6%、学習 1.6%。とくに2024年の冬は12日）。AP は大雪日の割合が高いほど大きく出やすいので、評価の AP は CV より高めに出ている。
- 評価データの大雪日は20日（2冬）だけで、AP・AUC・的中日数の区間は広い。多重比較の補正はしていない。
- ロジスティック回帰は、クラス重みに加えて正則化の強さ C も探索範囲の端に張りついている（S0・SA で C = 1.8〜3.5e-4、下限は 1e-4。重みの範囲を500倍に広げた確認では 5〜9e-5 と範囲の外へ出た）。最適な設定は見つけきれていない。
- CVスコアは100試行の中の最良値なので楽観的。勾配ブースティング・ランダムフォレストは学習データとの当てはまりの差（過学習のギャップ）が大きい。
- 勾配ブースティング分類は確率の較正をしておらず、学習データを完全に覚えている。判定の線が不安定なので、分類の結論はロジスティック回帰を主にして読む。
- ロジスティック回帰のクラス重み（20cm）は本番の探索（1〜50倍）で S0 39.7〜46.8倍、SA 29.3〜32.5倍、SB 1.0〜1.1倍。CVだけで上限を500倍に広げて試すと、S0 378倍、SA 320倍と範囲の上のほうが選ばれたが、CV AP は S0 0.038 → 0.039、SA 0.051 → 0.051、SB 0.260 → 0.261 で、ほとんど変わらなかった（`logs/hirosaki/check_logreg_weight_range.log`）。最適な重みは見つけきれていない。
- 弘前の降雪量の資料不足・欠測の5日（2020年の冬）は除いた。評価データには欠損はない。
- 弘前の湿度は2021年3月以前に観測がないため使っていない。寒さ×湿度の項目は青森の湿度で作っている。
- 大雪の閾値は20cm（主）と15cm（参考）。15cm は学習データから決め、評価の前に決めた。
- 地点は弘前1地点、冬は11〜3月だけ。2016〜2026年の間の気象庁のモデルの改良による値のくせの変化は確認していない。
